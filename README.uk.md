# Студія рілсів — коротко для Марини

Студія сама монтує рілси для брендів (TOSUMI, YOCASE): субтитри, вставки, музика, звуки. Ти даєш відео і бриф,
Claude показує чернетку, ти пишеш правки звичайними словами — і отримуєш готовий рілс.

## Як почати рілс

1. Відкрий застосунок Claude → вкладка **Code** → папка **reel-studio**.
2. Напиши, наприклад: «новий рілс для YOCASE: подарунок подрузі» (або `/reel`).
3. Відкриється папка цього рілса у Finder. Перетягни туди відео з телефона (з iPhone — через AirDrop, потім із
   «Завантажень» у папку рілса). Картинки й відео для вставок клади в папку **inserts** всередині.
4. Бриф напиши у файлі **brief.md** у тій самій папці або просто текстом у чаті.
5. Напиши «файли там». Claude готує відео (кілька хвилин), робить чернетку і відкриває її.

Один рілс — одна сесія. Для наступного рілса відкрий нову сесію.

## Бриф

Заповнюй лише те, що важливо; порожнє Claude вирішить сам і напише, що обрав.

- **БРЕНД:** TOSUMI або YOCASE
- **ФОРМАТ:** порожньо — говорюча голова; або лінійка, скетч, лише субтитри
- **ІДЕЯ:** про що рілс
- **ХУК:** текст на екрані на початку, дослівно
- **КОДОВЕ СЛОВО:** якщо в кінці кажеш «напиши …»
- **МУЗИКА:** назва треку, «без музики», або порожньо — музика бренду
- **ЦЕНЗУРА:** слова через кому — у субтитрах будуть із зірочкою (гр*ші)
- **ВСТАВКИ:** «коли кажу “набір” — покажи set.jpg», «… на весь екран», «… без звуку»
- **БЕЗ ПРАВОК СТИЛЮ:** «так» — тільки стиль бренду, без додаткової графіки
- **ШВИДКІСТЬ:** зазвичай порожньо
- **ПРИМІТКИ:** усе інше

## Зйомка

- HDR-відео вимкнене: Параметри → Камера → Запис відео → HDR-відео.
- Невдалий дубль: скажи «стоп» і почни фразу спочатку.

## Що писати Claude

- Правки — звичайними словами: «субтитри вище», «музика тихіше», «прибери вставку з коробкою».
- «фінал» — фінальна версія рілса і ще одна, без музики.
- «для DaVinci» — після фіналу, якщо хочеш доробити рілс у DaVinci Resolve.
- «готово» або «опублікувала» — рілс іде в архів, і Claude запропонує звільнити місце на диску. Тут Claude
  попросить дозвіл на видалення — натисни «Так». Потім він надішле на GitHub зміни, які ви зробили під час рілса.
- «правка до рілса …» — відкрити рілс з архіву, коли бренд просить зміну.
- «онови студію» — підтягнути свіжі зміни студії, твої й Владові (лише між рілсами).
- «перевір студію» — перевірка, що все працює.
- «звіт для Влада» — якщо щось не так.

## Де результат

Папка **output**: `…_draft.mp4` — чернетка, `….mp4` — фінал, `…_no_music.mp4` — без музики (щоб додати трендовий
звук в Instagram), `…_project` — проєкт для DaVinci. Після «готово» папка рілса (відео, бриф, вставки) переїжджає в
папку **done**, а ролики лишаються в **output**.

## Поки Claude працює

Не закривай Claude, тримай Мак на зарядці й не закривай кришку. Підготовка відео і рендер можуть тривати кілька
хвилин; спитай «ну що там?», якщо цікаво.

## Як змінювати саму студію

Студія твоя так само, як і Владова: ти можеш її допилювати разом зі своїм Claude.

- Просто напиши, що хочеш змінити, звичайними словами: «для TOSUMI субтитри завжди трохи більші», «додай новий
  бренд …», «хочу ще такий шаблон вставки», «зроби, щоб музика в кінці стихала довше».
- Claude сам підтягне свіжі зміни, змінить код і налаштування, перевірить (тести, тестова чернетка), покаже, що
  вийшло, і пояснить простими словами. Після твого «так» він збереже зміни й надішле їх на GitHub — Влад отримає
  їх при оновленні, а ти так само отримуєш його.
- Коли Claude зберігає й надсилає зміни, він може попросити дозвіл — натисни «Так».
- Якщо зміна щось зламала — скажи Claude, він поверне попередню версію.

## Якщо щось зламалось

- Попроси Claude розібратися: «щось не так з …».
- Якщо не виходить — напиши «звіт для Влада». Claude покаже файл **developer_report.txt** у Finder — надішли його
  Владу.
- Не переміщуй і не перейменовуй саму папку reel-studio.
