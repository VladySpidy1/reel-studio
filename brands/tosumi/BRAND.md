# Brand: TOSUMI

TOSUMI's look **is** `pipeline/style_default.json` (the studio default), so every script without a brand still
renders in it. `brand.json` holds only what is TOSUMI's beyond that: the accent colour name, the grade, the music
bed, the SFX palette, the lint allowance for the grade and the hook/punchline looks. **Before changing
`style_default.json`, move its current values into `brand.json` here**, or every TOSUMI reel changes with it.
Numbers live only in the JSON files; this file holds the rules in words.

## Rules
- Lowercase, no punctuation; small text; white main text.
- Pink only on the fail/punch word, one per half-sentence; dream words in white serif.
- Only two big things in a reel: the interjection and the final punchline.
- Voice as recorded; a static music bed, no sidechain ducking (it audibly pumps).
- The client approved a stronger vignette than the playbook's ceiling, so the brand's lint profile allows it.

## Notes
- The punchline leading comes from the skit rules; `projects/tosumi_hair` used a tighter one. Noted, not migrated:
  tosumi_hair stays an untouched archive.

  is public: no brand book or NDA material here.
- Corrections from reels go to `learned/brands/tosumi.md` (gitignored); the developer promotes them into this file.
